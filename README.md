# Planta Tostadas

Repositorio del proyecto para organizar la documentación, datos y análisis relacionados con la producción de tostadas.

## Estructura del proyecto

- `docs/` → documentos del proyecto
- `data/` → datos de producción, humedad, merma y calidad
- `notebooks/` → análisis en Google Colab o Jupyter
- `src/` → scripts de Python

## Objetivo

Usar GitHub para ordenar el proyecto y Python para analizar producción, merma, humedad y trazabilidad.
